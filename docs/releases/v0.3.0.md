# 🚀 v0.3.0 — 2026-11-17

### ✨ Improvements

- 🔌 Claude Code and Claude Desktop can connect in proxy mode: Relo terminates TLS for the vendor on a loopback intercept, so the app runs unmodified. Pick the mode per agent and confirm changes with Save.
- 🖥️ Claude Desktop gets its own proxy mode and a Desktop picker you turn on from the agent modal. Relo's models appear in the Code picker, and Claude Code follows Desktop into proxy mode.
- 🧭 Bind Claude's native models to a Relo model or route in proxy mode. A bound request goes to Relo and falls back once. Relo's models are listed in Claude Code's picker.
- ☁️ Route Cowork through the picker behind its own switch.
- 🔐 One Relo certificate authority serves every client. Trust it system-wide on macOS, Windows and Linux only on request; the console warns, removes it and hands off the steps. A guide explains how to trust the certificate yourself.
- 🔁 The intercept keeps its port, token and certificate across daemon restarts.
- 🧮 The Messages token counter is answered.
- 📊 The console draws how environment and proxy mode reach Relo, and shows the status chips beside the agent modal title.
- ⭐ A Star on GitHub button sits beside the daemon status, with the star count.
- 🆕 The console shows what's new once per installed version.

### 🐛 Fixes

- 🍎 macOS system trust is written as the user and read back from the user's keychain; a root collector account is trusted for basicX509.
- 🔎 Tunnels whose client rejects the certificate are logged, and the hosts a picker connection asks for are counted.
- 🏷️ Parked models are named instead of their whole connection; unlabeled routes and connections show by id in the target list.
- ⏱️ A rate limit whose retry was cancelled is reported, and a half-open trial that never reports is ended.
- 🔄 Proxy mode survives a refresh and follows the intercept's new port; earlier intercept addresses count as stale, not foreign.
- 🧩 The Desktop picker loads from the right path, and the mode choice carries into the Add agent flow.
- 📦 The console installs again on Svelte 5 (`svelte-i18n` 4, `typescript-eslint` 8.73).
