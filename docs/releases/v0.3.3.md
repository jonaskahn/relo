# v0.3.3

## Lost-thread model exclusions

Older Claude lost-thread errors could leave persistent false model exclusions.
This upgrade discards only learned denials attributable to one complete retained
lost-thread provider response. Genuine denials, known account rosters, and
exclusions without sufficient historical evidence are left unchanged. A
model-list refresh alone did not repair the affected account observations.

An expired thread still requires a new conversation with the needed history;
Relo does not reconstruct missing conversations or replay tool actions.

The data repair advances the database version. A rollback to an older binary
requires a consistent pre-upgrade database backup, not deletion of the migration
record.
