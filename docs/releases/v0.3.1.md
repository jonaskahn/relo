# 🚀 v0.3.1 — 2026-11-17

### ✨ Improvements

- 🧦 Outbound proxies are now a managed pool instead of one address. Paste a list or import a file, and Relo validates each line, skips duplicates and reports what it refused. Passwords are kept in the credential vault, so a row holds no secret.
- 🎛️ Manage the pool from the Providers card: search, filter by enabled, cooling or disabled, page through it, then enable, edit, test or delete an entry. The card shows how many are enabled and how many are cooling.
- 🔁 A connection keeps one proxy while it stays healthy, and rotates to another when it fails. A proxy that fails cools down for a backoff and returns on its own; when every enabled proxy is cooling, the refusal names how long to wait.
- 🔐 SOCKS5 is accepted alongside HTTP and HTTPS, with `socks5h` stored as `socks5`. The `host:port:user:pass` shorthand that Settings already took now works here too.
- ↗️ A `[proxy] url` left in the startup file is moved into the pool once, and cleared only after the entry and its password are stored.
- 🩺 Doctor gains an **Outbound proxies** check, naming an unconfigured pool, a fully disabled one and one that is entirely cooling.
- 🌍 The proxy pool is named in all 23 console catalogs.

### 🐛 Fixes

- ⏱️ A rate limit longer than one request can wait now moves to the next account of the connection instead of holding the request open. When every account has answered, the refusal carries Relo's own `Retry-After` and a translated explanation rather than the vendor's body.
- 🆕 The what's-new dialog no longer reopens for the same release. Build metadata (`+b7df4346`) is dropped on both sides, so a beta rebuild and the catalog's spelling share one key.
- 🧩 The console takes `tailwind-variants` 4, `bits-ui` 2.21 and SvelteKit 3.2, with the dependency notices updated.

### 🧪 Quality

- 🧪 The proxy pool is measured end to end: its storage failures, selection and both cooling refusals, every API route's error, each doctor answer, the SOCKS5 and shorthand parsing, and the legacy move. `internal/proxy` went from 64.0% to 96.5%, and the coverage gate now lists it.
