# v0.2.0 - New Fire 🔥

🎉 **Introducing Free Connections (opt-in)**

- ⚙️ New `free connections` setting — off by default, you choose to enable it (found under **Others**)
- 🔒 Strict consent required before any free connection is used — enforced server-side in routing, not just in the UI
- 🎛️ Toggle free connections directly in the add picker, with per-connection overrides
- 🙈 Free gateways are hidden and renamed until you opt in
- ✨ Free-aware review controls, free model availability, and smarter free connection discovery
- 🌍 Rewritten consent copy, now fully localized (i18n)

🐛 **Fixes**
- 🐳 Fixed snapshot reload serialization
- 🧅 Fixed consent modal layering above the add modal
- 🔢 Fixed hidden free connection count not displaying

🪟 **Windows**

- 📦 npm no longer trips over version manager shims
