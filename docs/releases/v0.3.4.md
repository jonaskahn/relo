# v0.3.4

## Tool results with no text

A tool result that carries no spoken text, such as the reference Claude
Desktop's ToolSearch returns, is now sent to Chat upstreams as a short
placeholder instead of null content. Those upstreams rejected the whole
request with "tool message content must be a string…", which Claude Desktop
then surfaced as a failed turn.

## OpenAI-compatible agent

Agent Harness lists an **OpenAI-compatible** card for any client that speaks
the OpenAI Chat wire. It hands over the base URL, key, and model in manual
setup steps; Relo does not write that client's configuration file.

## Thread history for continued messages

Claude Desktop continues a thread by sending only the new message and the id
of the reply it answers. Relo now keeps each finished turn in its own
database and rebuilds the conversation before routing, so a follow-up keeps
its system prompt, tools, and earlier messages on every model, not only on
Anthropic. The window is 30 days by default and is set on the Claude detail
card; a turn older than the window is refused as a request error so the
client can resend it.
