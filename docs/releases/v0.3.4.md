# 🚀 v0.3.4 — 2026-11-20

### ✨ Improvements

- 🧵 Claude Desktop continues a thread by sending only the new message and the id of the reply it answers. Relo keeps each finished turn in its own table and rebuilds the system prompt, tools, and earlier messages before routing, so a follow-up keeps its context on every model, not only on Anthropic.
- ⏳ The window a stored thread stays continuable is set on the Claude detail card, 30 days by default. The setting saves inline, and the daemon sweeps turns past it on its maintenance tick. A turn older than the window is refused as a request error, so the client can resend it.
- 🤝 Agent Harness lists an **OpenAI-compatible** card for any client that speaks the OpenAI Chat wire. It hands over the base URL, key, and model in manual setup steps; Relo does not write that client's configuration file.

### 🐛 Fixes

- 📎 A tool result with no spoken text, such as the reference Claude Desktop's ToolSearch returns, is sent to Chat upstreams as a short placeholder instead of null content. Those upstreams rejected the whole request with "tool message content must be a string…", which Claude Desktop surfaced as a failed turn.
- 🧬 Learned model denials left behind by a lost thread are discarded. Only denials attributable to one complete retained lost-thread provider response are erased; genuine denials, known account rosters, and exclusions without sufficient evidence are left alone. A model-list refresh alone did not repair the affected observations.
