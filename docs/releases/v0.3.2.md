# 🚀 v0.3.2 — 2026-11-19

### ✨ Improvements

- 🛑 The Google Antigravity connection now ships switched off. Google disabled Cloud Code Assist for accounts it finds behind a third-party client, so requests through it are refused with a terms-of-service violation whatever the account's quota is. The connection, its accounts, its models and its usage stay, and the pane says why when you switch it back on.
- 🔓 Relo's own models are selectable in Claude Code and Claude Desktop in proxy mode. A row the picker greys out when it lacks a minimum version now carries one no client is below, so a custom model is no longer shown as unavailable.

### 🐛 Fixes

- 🆔 Antigravity requests carry the identity the current client sends — the `cli` family, its version, the matching changelist and the auth method. The previous version and changelist named a build the endpoint no longer serves.
- 🏷️ A turn whose prompt claims another vendor's agent is rewritten to speak as this transport. Relo relays Claude Code, Codex, OpenCode, Cursor, Cline and Kilo, and a prompt leading with one of their names earned a 429 that read as a spent quota; the task and harness rules behind that claim still travel.
- 📎 A tool answer travels in the model's turn, and a turn states no tool constraint the first-party client never sends. The envelope also labels its cascade, trajectory and request id and counts its step index from zero.
- 🧾 A refusal names the vendor's reason code beside its status, so a disabled account reads `PERMISSION_DENIED (TOS_VIOLATION)` instead of a bare status that looked like an ordinary throttle.
- 🧵 A lost thread is answered rather than retried. A 404 naming a thread is not a model refusal, and the thread belongs to the account that opened it, so the relay no longer spends every account of the connection on the same refusal.
- 🔗 The Anthropic surface echoes the upstream message id. Claude Code continues a thread by the id it was answered with, so Relo minting its own named a message the upstream never saw and turned the next turn into a thread-state failure.
- 🧬 The signed-out OpenCode lane rewrites a foreign agent identity too. A Claude Code prompt led with an Anthropic billing stamp, so the lane answered its generic usage-limit error, which reads as a spent quota.
- ⏱️ A cooling refusal rounds its `Retry-After` up, so a 90-second cooldown no longer goes out as 89 seconds and invite a retry the pool cannot take.

### 🧰 Maintenance

- 🎨 The Prettier formatter packages are pinned. The lockfile is deliberately not committed, so CI resolved a newer `prettier-plugin-svelte` whose style change failed the format gate on 60 files.
