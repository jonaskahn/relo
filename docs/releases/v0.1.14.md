## 🚀 v0.1.14

### ✨ Improvements

- More accurate provider-specific model capabilities, context limits, and reasoning settings—including models with on/off thinking.
- Console now displays provider-defined capability state.
- Bundled models.dev data provides a fallback when live data is unavailable.

### 🐛 Fixes

- Cursor: Fixed tool-call arguments, conversation replay, missing token usage, and retries for prematurely closed connections.
- Antigravity: Fixed Anthropic billing-stamp compatibility and respected provider-requested waits.
- Context handling: Prevented inflated image token estimates, fitted oversized output budgets to context limits, and returned client-compatible overflow errors.
- Tool requests: Removed tool_choice when no tools are declared, avoiding upstream failures during compaction.
- Windows npm installer: Fixed command-shim detection, terminal handling, and prompts stalling after the first question.

### 🧪 Quality

- Expanded regression coverage and enforced an 80% patch-coverage threshold.
