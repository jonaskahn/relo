# 🚀 v0.1.0 — 2026-10-15

Relo is a local LLM proxy between AI coding clients and upstream providers. Your agents keep their native protocol; Relo routes, pools accounts, and records usage and cost — all on loopback.

### ✨ What's in it

- 🔌 **Single-port data plane** at `127.0.0.1:10101`: `/inference/v1/*` speaks OpenAI-compatible, `/inference-claude/v1/*` speaks Anthropic.
- 🖥️ **Console + management API** on the same port: connect providers, manage accounts, routes, and client keys, inspect requests, review usage.
- ⌨️ **Daemon CLI**: `relo daemon run|start|stop|restart|status`, `autostart`, `uninstall`, `version`. Self-updating via installers.
- 🔁 **Account pooling & routing** with retries, failover cooldowns, and per-connection timeouts.
- 🔐 **Three credential classes**: admin token for the console, one-time-shown client keys for inbound traffic, provider credentials sealed in `secrets.enc` (or OS keychain).
- 📊 **Usage & cost tracking** with configurable overview cards.
- 🌍 Console in 23 languages, light/dark/system themes.
