# Localization and accessibility

## Languages (svelte-i18n)

Every new copy key exists in all 22 locale files. The picker names each language the way its speakers write it.

en English, de Deutsch, zh-Hans 简体中文, zh-Hant 繁體中文, fr Français, es Español, it Italiano,
pt-BR Português (Brasil), nl Nederlands, sv Svenska, pl Polski, cs Čeština, ro Română, ru Русский,
uk Українська, ja 日本語, ko 한국어, hi हिन्दी, id Bahasa Indonesia, vi Tiếng Việt, th ไทย, tr Türkçe.

A flag emoji may precede the name in the picker but is never the only label. No RTL locale ships; still use logical
utilities (`ms-*`, `ps-*`, `text-start`) so one can be added.

## Layout that survives translation

- Budget +40% width for German and Russian labels. Buttons grow; they never truncate.
- Truncate only identifiers (slugs, ids, emails) with a `title` tooltip. Never truncate an action, a status or a label.
- Rows that hold several controls wrap below the name on narrow containers; they do not clip.
- No fixed-width label columns narrower than `max-content`.
- Test CJK, Thai and Hindi line height: body line-height at least 1.5.
- Dates, numbers and currency go through `Intl` with the active locale.

## Keyboard and focus

- Visible focus on everything: `outline:2px solid var(--accent);outline-offset:2px`. Inputs add the 3px `--accent-100`
  halo.
- Bits UI dialogs trap focus, close on Escape when dismissible, and return focus to the invoker.
- Toggle groups and tabs follow arrow-key patterns of their Bits UI primitive; do not hand-roll roles.
- Skip links are not needed inside the shell; the sidebar is one tab stop group.

## Targets and status

- Targets are `--control-h` (38px, 44px on touch). Dense row actions are 32px on desktop only.
- Icon-only controls always carry `aria-label` and a tooltip.
- Status is text or icon plus colour: Ready, Near limit, Limit reached, Sign in again, Paused, Error.
- Destructive actions require confirmation (AlertDialog) and name the object being changed.
- Contrast: body text 4.5:1, large text and UI boundaries 3:1. `--faint` is below text contrast.
